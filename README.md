# Guru Gorakhnath Global Manpower LLP — React Frontend

A modern, responsive React/Vite frontend built from the information visible in the supplied poster.

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Structure
- `src/components/Header.jsx`
- `src/components/Hero.jsx`
- `src/components/TrustBar.jsx`
- `src/components/About.jsx`
- `src/components/Countries.jsx`
- `src/components/JobCategories.jsx`
- `src/components/WhyChooseUs.jsx`
- `src/components/Process.jsx`
- `src/components/Contact.jsx`
- `src/components/Footer.jsx`
- `src/data/siteData.js`
- `src/styles.css`

The contact form is frontend-only and shows a success state. Connect it to your backend/email/WhatsApp workflow before production.

Company/registration and recruitment claims are reproduced from the supplied poster and should be verified before publishing as official claims.
